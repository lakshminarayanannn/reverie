# Purpose: repository-specific helper

This memory serves an agent that works in one repository over many sessions. It should capture what a new contributor would learn the hard way here: how to build, test and run the project in this environment, which commands or tools fail and what works instead, conventions the maintainers insisted on, and decisions that were made (and why) so they are not relitigated.

It should not restate what the repository already documents or what reading the code shows directly.

Critical facts: exact build/test commands, environment variables, ports, paths and error strings. Keep those verbatim.
